# Changelog

All notable changes to this project are documented in the [GitHub Releases](https://github.com/zumik3-del/ziptask/releases).

## v0.9.0

Current release. Dependency and CI maintenance — Dependabot replaced by a self-hosted Renovate run, with GitHub Actions, Bun and lock-file pins updated — plus the config-independent `--version`/`--help` handling and the experimental read-API error fixes merged since v0.8.0. See the [release notes](https://github.com/zumik3-del/ziptask/releases/tag/v0.9.0) for details.
